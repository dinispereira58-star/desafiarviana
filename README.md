# Desafiar Viana — CRM

Gestão de pedidos de marcação recebidos do site público (animacao-turistica-site). React + Vite + Tailwind + Supabase.

## Desenvolvimento

```
npm install
npm run dev
```

Precisa de um ficheiro `.env` (ver `.env.example`) com as credenciais do projeto Supabase.

## Base de dados

```
npx supabase db push --linked
```
